> **Track:** Backend Development | **Level:** Intermediate

---

## 📌 1. Project Overview

Production-ready Car Rental & Vehicle Fleet Management API built using Node.js, Express.js, and Supabase. The system manages fleet vehicles, user authentication via Supabase JWT, automated rental billing calculations, and complex date-range overlap collision prevention algorithms to prevent vehicle double-booking.

### Key Features
- **Relational PostgreSQL Schema**: `vehicles` and `rentals` tables with foreign keys, constraints, and timestamps.
- **Date Range Collision Prevention**: Prevents double-booking by enforcing SQL / JS date overlap checks `(start_date <= existing_end) AND (end_date >= existing_start)`.
- **Dynamic Billing Computation**: Computes dynamic total cost `(days * daily_rate)` on the server side.
- **Fleet State Management**: Automatic transition of vehicle status (`available` ➔ `rented` ➔ `completed`/`available` or `maintenance`).
- **Supabase Auth Guards**: Customer registration, login, JWT token issuance, and protected booking routes.

## 🗄️ 3. Database Schema (Supabase SQL)

Run the following SQL in your Supabase SQL Editor:

```sql
-- 1. Vehicles Table
CREATE TABLE vehicles (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    brand TEXT NOT NULL,
    model TEXT NOT NULL,
    year INT NOT NULL,
    category TEXT NOT NULL CHECK (category IN ('Sedan', 'SUV', 'Luxury', 'Hatchback', 'Electric')),
    daily_rate NUMERIC(10, 2) NOT NULL CHECK (daily_rate > 0),
    fuel_type TEXT NOT NULL,
    seating_capacity INT NOT NULL DEFAULT 5,
    status TEXT NOT NULL DEFAULT 'available' CHECK (status IN ('available', 'rented', 'maintenance')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Rentals / Bookings Table
CREATE TABLE rentals (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id UUID NOT NULL, -- references Supabase auth.users
    vehicle_id BIGINT REFERENCES vehicles(id) ON DELETE RESTRICT,
    customer_name TEXT NOT NULL,
    customer_email TEXT NOT NULL,
    start_date DATE NOT NULL,
    end_date DATE NOT NULL,
    total_cost NUMERIC(10, 2) NOT NULL,
    status TEXT NOT NULL DEFAULT 'booked' CHECK (status IN ('booked', 'active', 'completed', 'cancelled')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    CONSTRAINT valid_date_range CHECK (end_date >= start_date)
);
```

## 🚀 4. Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone <repository_url>
   cd ASSIGNMENT\ 10
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Copy `.env.example` to `.env` and fill in your Supabase URL and Key:
   ```env
   PORT=5000
   SUPABASE_URL=https://your-supabase-project.supabase.co
   SUPABASE_ANON_KEY=your-supabase-anon-key
   ```

4. **Run Server**:
   ```bash
   # Production Mode
   npm start

   # Development Mode (Nodemon)
   npm run dev

   # Run Integration Tests
   npm test
   ```

## 📋 5. API Endpoints Specification

### 🔐 Auth Endpoints (`/api/auth`)
| Method | Endpoint | Description | Request Body Example | Status Codes |
|---|---|---|---|---|
| `POST` | `/api/auth/register` | Register customer | `{"email":"driver@travel.com","password":"mypassword123","name":"David"}` | `201 Created`, `400 Bad Request` |
| `POST` | `/api/auth/login` | Login & receive Bearer Token | `{"email":"driver@travel.com","password":"mypassword123"}` | `200 OK`, `401 Unauthorized` |

### 🚗 Vehicle Fleet Management (`/api/vehicles`)
| Method | Endpoint | Auth Required | Description | Request Body Example | Status Codes |
|---|---|---|---|---|---|
| `GET` | `/api/vehicles` | No | Fetch all vehicles (supports `?category=SUV&status=available`) | None | `200 OK` |
| `GET` | `/api/vehicles/:id` | No | Get vehicle details with past rental records | None | `200 OK`, `404 Not Found` |
| `POST` | `/api/vehicles` | Yes | Add new vehicle to fleet | `{"brand":"Tesla","model":"Model 3","year":2024,"category":"Electric","daily_rate":4500,"fuel_type":"EV","seating_capacity":5}` | `201 Created`, `400 Bad Request` |
| `PUT` | `/api/vehicles/:id` | Yes | Update vehicle daily rate or status | `{"daily_rate":4800,"status":"maintenance"}` | `200 OK`, `404 Not Found` |
| `DELETE` | `/api/vehicles/:id` | Yes | Delete vehicle from fleet | None | `200 OK`, `400 Has Active Bookings` |

### 📅 Rental & Booking Operations (`/api/rentals`)
| Method | Endpoint | Auth Required | Description | Request Body Example | Status Codes |
|---|---|---|---|---|---|
| `POST` | `/api/rentals` | Yes | Book vehicle (Collision check & auto billing) | `{"vehicle_id":1,"start_date":"2026-05-01","end_date":"2026-05-05","customer_name":"David","customer_email":"david@test.com"}` | `201 Created`, `400 Collision/Error` |
| `GET` | `/api/rentals/my-bookings` | Yes | List rentals for authenticated user | None | `200 OK` |
| `PATCH` | `/api/rentals/:id/cancel` | Yes | Cancel upcoming rental | None | `200 OK`, `400 Cannot Cancel` |
| `PATCH` | `/api/rentals/:id/complete` | Yes | Mark car as returned (resets vehicle status to available) | None | `200 OK` |
